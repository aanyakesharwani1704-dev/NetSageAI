# Features

## Rule-Based Diagnosis

Known network signatures are matched using deterministic rules and regular expressions.

## AI-Assisted Diagnosis

Relevant case evidence can be passed to an LLM for structured diagnostic reasoning.

## Confidence

Diagnoses include confidence information so reviewers can judge reliability.

## Human Review

A reviewer can accept, edit, or reject an AI-generated diagnosis.

## Auditability

Review information is recorded for later analysis and accountability.
