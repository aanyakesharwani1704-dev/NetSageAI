# Usage

1. Start the Streamlit application.
2. Select or enter a troubleshooting case.
3. Provide the relevant network evidence.
4. Run diagnosis.
5. Inspect deterministic findings and AI-assisted reasoning.
6. Review the suggested root cause, evidence, confidence, next command, and fix steps.
7. Record the human review decision.

The system is intended as decision support. Suggested fixes should be verified by an appropriate network administrator before execution.
